# Coding Practice Repository

A collection of coding challenges and exercises to practice algorithms, data structures, and problem-solving skills in 
Kotlin.

## Structure

### `codewars/`
LeetCode-style algorithmic challenges and competitive programming problems.

### `training/`
Foundational programming exercises covering core concepts and data structures.

## Running Tests

This project uses [Kotest](https://kotest.io/) for testing. Each file contains both the problem implementation and 
corresponding test cases.

To run all tests:
```bash
./gradlew test
```

To run a specific test file:
```bash
./gradlew test --tests "ClassName"
```

## Practice Approach

Each problem includes:
- Clear problem description with examples
- Test cases covering edge cases
- Implementation space for solutions

Solutions range from beginner-friendly exercises to more complex algorithmic challenges, making this suitable for 
continuous skill development.

## Notes

Some solutions include inline comments with learnings and optimization insights discovered during the problem-solving 
process.
